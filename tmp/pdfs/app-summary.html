Repo Summary

coupon-site

CouponHub/CouponPush is a coupon and deals web app with shopper-facing pages plus an admin CMS for managing stores, coupons, deals, messages, and settings. The repo contains a React storefront, PHP-rendered pages, PHP JSON APIs, and a MySQL schema.

Who It's For

Primary persona: price-conscious online shoppers in India looking for verified promo codes, store-specific offers, and seasonal savings across categories like electronics, fashion, food, travel, beauty, and grocery. Admin operators are also supported through repo-backed management pages.

What It Does

  • Shows featured and latest coupons, featured stores, and featured deals on the homepage.
  • Organizes offers by store, category, coupon page, and search results.
  • Supports seasonal or festival offer pages through dedicated seasonal offer tables and API routes.
  • Tracks coupon and deal clicks through `/api/track-click.php` and click counters in MySQL.
  • Captures newsletter subscribers and contact form messages in database tables.
  • Adds SEO metadata and schema markup on home, store, and search pages.
  • Provides admin pages for coupons, stores, categories, deals, settings, subscribers, and messages.

How It Works

  • Frontend: `frontend/src/App.tsx` wires React Router pages such as home, store, category, coupon, search, contact, privacy, and seasonal offers.
  • Data access: `frontend/src/services/api.ts` fetches `/api/*.php` endpoints for stores, coupons, deals, categories, seasonal offers, search, stats, and click tracking.
  • Backend/API: `api/config.php` sets JSON/CORS helpers; endpoint files query MySQL and return `{ success, data }` responses.
  • Shared services: `config/database.php` provides a PDO singleton, while `includes/functions.php` centralizes helpers, search, click tracking, featured content queries, auth checks, and settings reads.
  • Storage/admin: `database/schema.sql` defines users, categories, stores, coupons, deals, subscribers, contact_messages, click_tracking, and settings; `database/seasonal_offers.sql` extends this for seasonal campaigns; `admin/*.php` manages the same data.

How To Run

  1. Import `database/schema.sql` into MySQL. Import `database/seasonal_offers.sql` if you want seasonal offer support.
  2. Set DB credentials in `config/database.php`.
  3. Serve the repo from a local PHP/Apache path matching `http://localhost/coupon-site` and start MySQL; the repo references XAMPP Apache in `HomePage.tsx`, and `frontend/vite.config.ts` proxies `/api` and `/uploads` to that URL.
  4. In `frontend/`, run `npm install` then `npm run dev` to launch the React app on port `5173`.

One-command local bootstrap, Docker, or Compose setup: Not found in repo.

Repo note: branding is mixed in source and docs (`CouponHub` in schema/deployment/settings, `CouponPush` in React SEO and UI copy).
