# CouponPush SEO fixes — 12 October 2026

The May 10 Semrush screenshot is historical and capped at 100 pages. The current live sitemap audit checked 58 pages. All returned 200 at their listed URL, with one matching HTML canonical, no detected noindex directive, and unique titles and descriptions within that set. One image returned 404. HTTP still serves the homepage without redirecting to HTTPS, and the www hostname did not resolve from this environment.

## Changes ready locally

- Added an initial-HTML fallback for Kapiva coupon 26's image, `/uploads/coupons/coupon_1771744195_699aabc3282ff.jpg`. The original was confirmed missing on the frontend, media, and API hosts. Both saved-snapshot rendering and browser API normalization already use the shared fallback helper. The source catalog keeps its original reference for later restoration.
- Added a Cloudflare Worker that permanently redirects HTTP and www requests on the public domain to `https://couponpush.com`, preserving paths and query strings. Canonical requests delegate to the static assets binding. The existing legacy redirects and 404 behavior remain effective.
- Updated Wrangler to invoke this Worker before asset lookup, and excluded the Worker source from public assets. Cloudflare's static redirect file cannot implement origin redirects; see [redirect rules](https://developers.cloudflare.com/workers/static-assets/redirects/) and [Worker-first routing](https://developers.cloudflare.com/workers/static-assets/routing/worker-script/).
- Added image-response and origin-regression checks to both build commands. Image auditing now includes responsive srcset variants and picture sources.
- Strengthened live auditing to report duplicate/missing metadata, redirected sitemap URLs, additional HTTP canonical headers, and incomplete sitemap discovery, and return a failing exit code when issues remain. Export SEO checks also reject multiple canonicals on noindex pages.
- Updated older storefront assertions for the existing active-inventory policy: expired offers do not keep a page indexable or require offer-specific evidence/report links in the rendered page. Several fixture merchants' offers expired on October 5. Their titles, canonicals, guides, FAQs, and alias redirects are still checked.
